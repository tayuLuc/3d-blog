Любой ИИ-агент — от простейшего бота до автономной системы — начинается с одного и того же: запрос улетает в темноту, и оттуда возвращается ответ. Разберём этот «ящик» — а заодно побудем внутри него.

01

01 · Интерфейс

Коробка с двумя отверстиями

Если смотреть на агента снаружи, видно на удивление мало. Ни памяти, ни плана, ни характера — только два отверстия: одно принимает запрос, другое возвращает ответ. Этот интерфейс называется chat completions API, и через него сегодня разговаривает с моделями почти всё.

С этого начинают все конструкторы агентов: LangChain, OpenAI Assistants, Claude Agent SDK — под капотом любого из них лежит один и тот же обмен «сообщение → сообщение».

↗ СВЯЗЬ СО СЦЕНОЙКомната вокруг тебя — этот самый ящик. Янтарная щель слева — вход (request), голубой лоток справа — выход (response). Осмотрись: здесь больше ничего нет. Пока.
02

02 · Протокол

Анатомия запроса

Всё, что «знает» коробка, — массив messages. У каждого сообщения есть роль:

systemСкрытая инструкция: кто ты и как себя вести. Пользователь её не видит.
userТо, что прилетело снаружи. Капсула в щели — это оно и есть.
assistantОтвет коробки. Всё, что она «сказала» за свою жизнь.
request.json
{
  "model": "gpt-4o-mini",
  "messages": [
    { "role": "system", "content": "Отвечай кратко." },
    { "role": "user",   "content": "Сколько будет 7 × 8?" }
  ],
  "max_tokens": 64
}
response.json
{
  "choices": [{
    "message": { "role": "assistant", "content": "56" }
  }],
  "usage": { "prompt_tokens": 21, "completion_tokens": 2 }
}

Поле usage — счёт из коробки: сколько токенов сожгли. О токенах — следующая глава.

↗ СВЯЗЬ СО СЦЕНОЙНаведи прицел на капсулу — она покажет поле content входящего сообщения. Выстрел по лотку — отправить ответ.
03

03 · Валюта

Токены — валюта коробки

Коробка не читает слова — она читает токены: кусочки слов длиной в пару-тройку букв. По-английски один токен ≈ ¾ слова; по-русски дороже — слово часто распадается на два-три токена.

Всё, что влезает в коробку за один раз, называется контекстным окном. Это её единственная память: инструкция, запрос и весь разговор. Что не поместилось — не существует. Совсем.

↗ СВЯЗЬ СО СЦЕНОЙТвой боезапас — токены контекста: −1 за выстрел, +48 за отправленный ответ, немного капает само. Следи за шкалой слева внизу.
04

04 · Граница

Почему это ещё не агент

Chat completion — это один вдох: запрос → ответ. Коробка не умеет переспросить, не помнит тебя через пять минут и не вызовет калькулятор, даже если от этого зависит её жизнь. Честно говоря, она вообще не знает, что у неё есть лоток.

Агент начинается там, где ответ перестаёт быть концом и становится шагом. Для этого коробке понадобятся:

  • Цикл — observe → think → act, пока задача не решена. УРОВЕНЬ 1
  • Инструменты — function calling: коробка дёргает внешний мир. УРОВЕНЬ 2
  • Память — всё, что не влезло в контекстное окно. УРОВЕНЬ 3

А на последнем уровне ты соберёшь агента сам — из этих деталей, как из конструктора.

05

05 · Прозрение

Один вдох — не дыхание

На уровне 0 коробка была честна: запрос — ответ, один выстрел. Но термометр, который один раз ответил «22 градуса», никто не называет агентом.

Агент — это система, которая добивается цели в цикле: действует, смотрит на результат, поправляет себя. Ключевое отличие — не интеллект, а петля.

↗ СВЯЗЬ СО СЦЕНОЙСтены растворились: ты больше не в глухом ящике. Под ногами — сетка внешнего мира, в котором агент действует. Прокрути главу — рёбра каркаса подсветятся.
06

06 · Механика

Петля: наблюдай → думай → действуй

Внутри любого агента крутятся три фазы. Наблюдай — собери состояние мира. Думай — выбери действие. Действуй — измени мир. И снова по кругу.

На этой тройке держится всё: ReAct, агентные циклы в LangGraph, игровые ИИ, автопилоты, пишущие код. Различаются только станции — кольцо одно и то же.

↗ СВЯЗЬ СО СЦЕНОЙКольцо в центре комнаты — это и есть цикл. Янтарный узел — текущая фаза: стреляй по узлам в порядке НАБЛЮДАЙ → ДУМАЙ → ДЕЙСТВУЙ. Промах по фазе — сожжённый впустую контекст.
07

07 · Итерации

Шаг, ещё шаг

Одной тройки почти никогда не хватает. «Найди, где кофе дешевле»: наблюдал (цены) → думал (сравнил) → действовал (промежуточный вывод) → снова наблюдал (перепроверил) → …

Каждый виток стоит токенов — шкала слева внизу на этом уровне тает заметно быстрее. Работа агента стоит реальных денег, и валюта всё та же.

↗ СВЯЗЬ СО СЦЕНОЙПлашка «ШАГ 1/2» сверху — итерации задачи. После финального ДЕЙСТВУЙ капсула сама полетит в лоток.
08

08 · Границы

Когда остановиться

Петля без условия остановки — белка в колесе: двадцать одинаковых «подумал», цель поплыла, бюджет сгорел. На практике агента ограничивают: max_iterations, бюджет токенов, таймаут, критерий «цель достигнута».

Твоя шкала боезапаса — тоже бюджет. А кольцо, замедляющееся, когда ты стоишь, — это агент ждёт твоего действия, а не медитирует.

Не ясно одно: чем коробка действует? Пока из лотка вылетают только слова. На уровне 2 появятся инструменты — function calling.

↗ СВЯЗЬ СО СЦЕНОЙЗамри на пять секунд — цикл замедлится. Выстрел по фазе снова его разгонит.
