# Чёрный ящик

> Chat completion — самый простой способ взаимодействия с языковой моделью. Ты отправляешь массив сообщений, получаешь один ответ.

## Как это работает

```json
[
  { "role": "user", "content": "Что такое агент?" }
]
```

Запрос уходит в API, внутри происходит вычисление — **токены** расходуются на каждое слово, каждый символ. Ответ возвращается как новый элемент массива. Больше значений в запросе — больше токентов тратится.

## Что ты видишь в сцене

- **Капсула** — твой ответ, плавающий в пустоте
- **Лоток** — куда ты «стреляешь» токенами, обрабатывая запросы
- **Слот** — входное окно, куда падают новые сообщения
- **Свет от слота** — оранжевый, тёплый — как вспышка при получении запроса

## Попробуй

В режиме **3D** кликни по капсуле — она вспыхнет. Стреляй токенами в лоток — каждое попадание считается как решённая задача. Чем больше задач решено, тем выше счётчик справа.
