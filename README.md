# BLACKBOX/AGENT — как устроен ИИ-агент изнутри

Уровень 0: чёрный ящик (chat API). Слева — теория, справа — FPS изнутри коробки.

## Запуск
npm i && npm run dev

## Деплой
push в main → GitHub Actions → Pages.
В репозитории: Settings → Pages → Source: GitHub Actions.

## Управление
1 / 2 / 3 — режимы блог / вместе / 3d.
WASD — движение, мышь — обзор, ЛКМ — выстрел токеном, ESC — выйти.
