# Цикл ReAct

ReAct (Reasoning + Acting) — паттерн взаимодействия агента со средой через итеративный цикл:

1. **Observation** — агент видит текущее состояние
2. **Thought** — рассуждает о том, что делать
3. **Action** — выполняет действие (вызов инструмента)
4. **Observation** — видит результат
5. ...и так до финального ответа
