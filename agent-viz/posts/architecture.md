# Архитектура AI-агентов

AI-агент — это система, которая воспринимает среду, принимает решения и действует для достижения целей. В основе лежит цикл восприятие → мысль → действие.

## Ключевые компоненты

- **Ядро (LLM)** — принимает решения на основе контекста
- **Память** — хранит историю взаимодействий
- **Инструменты** — внешние API, базы данных, поиск
- **Планировщик** — разбивает сложные задачи на подзадачи
