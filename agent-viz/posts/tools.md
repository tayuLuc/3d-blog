# Инструменты агента

Инструменты расширяют возможности агента за пределы генерации текста:

- **Web Search** — поиск актуальной информации
- **Code Interpreter** — выполнение кода
- **API Calls** — обращение к внешним сервисам
- **File I/O** — чтение/запись файлов

Каждый инструмент описывается в schema (function calling). Агент сам решает, когда и какой вызывать.
