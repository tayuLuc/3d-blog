# Мультиагентные системы

Когда задача слишком сложна для одного агента, её распределяют между несколькими специализированными агентами:

- **Orchestrator** — координирует подагентов, агрегирует результаты
- **Specialists** — узкие эксперты (код, дизайн, анализ данных)
- **Critic** — перепроверяет результаты других агентов

Такая архитектура повышает качество ответов и надёжность системы.
