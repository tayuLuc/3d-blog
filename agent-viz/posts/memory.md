# Механизмы памяти

Агенты нуждаются в памяти разных уровней:

## Short-term (рабочая)
Контекст текущего диалога — что агент видит «прямо сейчас».

## Long-term (долгосрочная)
Векторная база данных для семантического поиска по прошлым взаимодействиям.

## Episodic (эпизодическая)
Запись конкретных событий прошлых диалогов для воспроизведения контекста.
